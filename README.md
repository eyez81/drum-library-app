# Drum Library

אפליקציית קטלוג אישית למערכות תופים, תופים בודדים ומצילות עבור GitHub Pages.

## קבצים
- `index.html` – מבנה האפליקציה
- `styles.css` – עיצוב כהה ורספונסיבי
- `app.js` – חיפוש, סינון, תצוגות וחלונות מידע
- `data.js` – כל הנתונים
- `images/` – תמונות מקומיות מתוך ה-VST

## שתי ספריות
1. **מערכות תופים** – מערכות מלאות עם רשימת כל התופים והמצילות.
2. **פריטים בודדים** – סנרים, קיקים, טומים ומצילות שהותקנו בנפרד ואינם חייבים להשתייך ל-Kit מלא.

## שני סוגי תמונות
לכל מערכת או פריט ניתן לשמור שני שדות תמונה שונים:

- `image` – תמונה מקומית, בדרך כלל צילום מסך מתוך ה-VST, לדוגמה `images/REGAL.png`.
- `realImageUrl` – קישור ישיר לתמונה אמיתית באינטרנט.

כאשר למערכת מלאה קיימות שתי התמונות, תמונת ה-VST נשארת התמונה הראשית ובתוך עמוד המערכת מוצגת גם **תמונה אמיתית** בגודל גדול.

בפריט בודד, אם אין תמונה מקומית אך קיים `realImageUrl`, התמונה מהאינטרנט משמשת גם כתמונה הראשית של הכרטיס וגם בעמוד הפריט.

### חשוב לגבי קישורים לתמונות
יש להעדיף **קישור ישיר לקובץ תמונה** שמסתיים בדרך כלל ב-`.jpg`, `.jpeg`, `.png` או `.webp`, ולא קישור לעמוד מוצר. האתר מציג את התמונה עצמה ואינו שולח את המשתמש לאתר החיצוני.

חלק מהאתרים חוסמים הצגת תמונות שלהם בתוך אתרים אחרים (hotlink protection). במקרה כזה האפליקציה תציג הודעה שהתמונה לא ניתנת לטעינה. אם זה קורה, הפתרון האמין ביותר הוא לשמור עותק של התמונה בתיקיית `images/`.

## הוספת פריט בודד
בסוף `data.js` קיים מערך בשם `DRUM_STANDALONE_PARTS` ובתוכו דוגמה מוכנה (כרגע כהערה). לכל פריט ניתן לשמור סוג, גודל, חברה, דגם, הרחבה, SDX/EZX, תוכנה, טכנאי/מפיק, preset, mix, תמונה מתוך VST ותמונה אמיתית מהאינטרנט.

## GitHub Pages
העלה את כל תוכן התיקייה לשורש ה-repository והפעל GitHub Pages מה-branch הראשי.
